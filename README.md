# 🛍️ RetailIQ — Customer Shopping Behavior Analysis

An end-to-end **Data Analytics project** analyzing customer shopping behavior using **Python, SQL, and Power BI**.

## 📌 Project Overview

The project analyzes customer demographics, purchasing patterns, product performance, discounts, subscriptions, and spending behavior to generate actionable business insights.

## 🛠️ Tools Used

* **Python** – Data cleaning & EDA
* **SQL** – Business analysis
* **Power BI** – Interactive dashboard
* **Pandas & Jupyter Notebook** – Data analysis
* **Generative AI** – Productivity & documentation

## 🔄 Workflow

**Data → Cleaning → Python EDA → SQL Analysis → Power BI Dashboard → Business Insights**

## 📊 Key Outcomes

* Identified important customer segments
* Analyzed product and category performance
* Studied customer spending and purchase patterns
* Analyzed discount and subscription behavior
* Created an interactive Power BI dashboard

## 📂 Files

* `Customer_Shopping_Behavior_Analysis.ipynb` — Python analysis
* `customer_behavior_sql_queries.sql` — SQL queries
* `customer_behavior_dashboard.pbix` — Power BI dashboard
* `customer_behaviour_shopping.csv` — Dataset
* `Customer-Shopping-Behavior-Analysis.pdf` — Report

**Python | SQL | Power BI | Data Analysis | EDA | Data Visualization | Business Intelligence | Generative AI**
